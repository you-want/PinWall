# 便签提醒功能实现

## Task 1: 扩展数据模型
- 修改 `desktop/src/types/index.ts` 中 `PinCardData`，新增字段：
  - `reminderEnabled: boolean` (默认 false)
  - `reminderTime: number | null` (时间戳，毫秒)
  - `reminderFired: boolean` (是否已触发提醒，避免重复)

## Task 2: 新建便签时添加提醒开关和时间选择器
- 修改 `desktop/src/components/NewCardModal.tsx`：
  - 在"颜色"选择下方增加"提醒"开关（toggle），默认关闭
  - 开启后显示日期时间选择器（`<input type="datetime-local" />`）
  - `onConfirm` 回调签名扩展为 `(title, content, colorIndex, reminderEnabled, reminderTime)`
  - 新增对应 CSS 样式

## Task 3: Wall 页面处理提醒数据
- 修改 `desktop/src/pages/Wall.tsx`：
  - `handleCreateCard` 接收并保存提醒相关字段到卡片数据
  - 添加定时器（`setInterval` 每秒检查），遍历所有卡片，找到 `reminderEnabled && !reminderFired && reminderTime <= Date.now()` 的卡片
  - 触发提醒时：标记该卡片 `reminderFired = true`，显示通知弹窗

## Task 4: 创建通知弹窗组件
- 新建 `desktop/src/components/ReminderNotification.tsx`：
  - 从屏幕右上角滑入的半透明卡片，显示便签标题和内容摘要
  - 播放"叮"的提示音（使用 Web Audio API 生成简短合成音，无需音频文件）
  - 两个操作按钮：「全屏查看」和「关闭」
  - 点击「全屏查看」将对应便签设为全屏模式
  - 点击「关闭」仅关闭通知弹窗
  - 添加对应的 CSS 动画样式（从右侧滑入/滑出）

## Task 5: 关闭便签增加二次确认
- 修改 `desktop/src/components/PinCard.tsx`：
  - 点击关闭按钮时，不直接调用 `onClose`，而是显示确认弹窗
  - 使用已安装的 `@tauri-apps/plugin-dialog` 的 `confirm` 方法弹出原生确认对话框："确定要删除这个便签吗？"
  - 用户确认后才执行 `onClose(card.id)`

## Task 6: 添加 CSS 样式
- 在 `desktop/src/App.css` 中添加：
  - 提醒开关 toggle 样式
  - 时间选择器样式
  - 通知弹窗的滑入/滑出动画
  - 通知弹窗的布局和按钮样式

## Task 7: 验证和测试
- 确保 TypeScript 编译通过
- 验证提醒数据正确持久化到 localStorage
- 确认关闭二次确认正常工作
