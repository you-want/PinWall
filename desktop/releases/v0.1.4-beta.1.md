# PinWall 0.1.4-beta.1 — macOS 内测

本版先作为草稿内测包验收，使用手动下载安装。macOS 包采用 ad-hoc 签名、未做 Apple 公证；不代表正式分发版本。CI 产物为同时包含 Apple Silicon / Intel 的 universal DMG，两个架构仍须分别实机验收。

## 本版改进

- 便签支持编辑标题、正文、颜色和提醒；启动后保留自定义位置。
- 便签日常保存使用原生增量合并和原子替换。失败时保留草稿并提供重试，跨窗口恢复会同步到打开的便签墙。
- 设置使用 revision 事务，损坏数据保留原文件及备份并停止覆盖。
- 设置页支持便签导出和合并恢复；同 ID 保留本地便签，导入提醒默认关闭。
- macOS AI / 额度密钥迁移到 Keychain，权限拒绝或提交失败时保留旧数据。
- 提醒使用共享心跳，避免异步回调重叠；增加浏览器和原生持久化回归覆盖。

## 安装与升级

1. 在旧版本导出便签备份，另行保存必要的设置。涉及密钥迁移时，建议先在独立 macOS 测试账户使用假密钥验收。
2. 从托盘退出旧版，再安装本版；不要同时运行新旧实例。
3. 对照 `SHA256SUMS.txt` 核对下载的 DMG，再安装和首次启动。遇到系统安全提示时，仅对已核对来源的测试包使用“系统设置 → 隐私与安全性 → 仍要打开”；不要关闭系统安全机制。
4. 验证创建、编辑、拖拽、退出重开、提醒、备份恢复和 Keychain 权限，详见仓库 `desktop/BETA_TESTING.md`。

## 已知边界

- 保存失败的草稿只在当前窗口内存中，成功重试前请保持应用打开。
- 通知排队、本地日期/时区边界、睡眠唤醒和桌面层级仍需实机验证；本版仅合并调度定时器，没有完成这些行为的全面重构。
- 其他五个 store 仍由原插件持久化，损坏数据暂无应用内修复向导。
- 历史副本可能仍含旧明文密钥，不会自动修改；迁移后的设置不要直接交给旧版应用覆盖使用。
- 自动更新未开放；回退应先退出应用，并从升级前备份恢复对应版本数据。
