# 可选原生插件契约

本轮属于 P2 实验能力，复用已有 Widget Hub、安装器和桌面卡片。当前包含防休眠、系统监控、剪贴板转便签、图片识字、图片工具、剪贴板历史、文件暂存架、屏幕工具、本地工具、音频与媒体、窗口工具、输入增强、视频工具、系统维护、EDR 显示增强和风扇/合盖，十六项均默认关闭；防休眠需用户主动开始，不自动恢复运行。截图仅按需启动固定系统截图程序，不新增常驻独立服务进程，不扩大 Tauri capability，不改动便签/设置持久化 schema；暂存架使用独立版本化索引。

## 安装与资源

源码位于 `desktop/resources/widgets/` 的 `widget-keep-awake/`、`widget-system-monitor/`、`widget-clipboard-note/`、`widget-ocr-note/`、`widget-image-tools/`、`widget-clipboard-history/`、`widget-file-shelf/`、`widget-screen-tools/`、`widget-local-tools/`、`widget-music/`、`widget-window-tools/`、`widget-input-tools/`、`widget-video-tools/`、`widget-maintenance/`、`widget-display-tools/`、`widget-hardware-tools/`，随应用打包至 `native-widgets/`；其余官方组件沿用现有资源目录。系统监控保留 ID `com.pinwall.system-monitor`，升级至 2.0；旧版不会自动替换，需从组件中心重新安装。安装后仍存入 AppData 下的 widgets 目录。

Manifest 支持可选字段 `defaultEnabled`；原生操作使用独立 `power`、`clipboard` 权限，监控使用已有 `system` 权限。新安装组件按 `defaultEnabled ?? true` 初始化，兼容既有组件；同步已有安装时保留用户的启用选择。十六项工具固定为 `false`，安装授权不会启动原生能力。覆盖安装会重新关闭；普通启动同步保留现有启用状态和尺寸。

`type: official` 不能授予原生权限。Rust 在打开电源会话、读取剪贴板、操作图片、历史、暂存架或屏幕前校验各自固定 ID、安装目录及三个入口文件的精确字节，拒绝符号链接、路径逃逸和修改后的组件。更新应用后旧组件内容若不匹配，需要重新安装；UI 提供说明。这是内置可信源机制，不是第三方签名、市场审核或自动更新系统。

## iframe 与消息协议

Widget 入口由宿主读取 HTML，再通过 `srcDoc` 加载。iframe 只授予 `allow-scripts`，保持不透明 origin；宿主仅接受当前 iframe 窗口且 origin 为 `null` 的消息。宿主插入首条 CSP，禁止直接连接网络、外部脚本/样式、子 frame、表单和对象；图片仅允许 data/blob。原有依赖外部资源、同源 DOM、localStorage 或跨文件脚本的本地组件可能需要改为内联资源并使用 bridge。

请求形式：

```json
{"type":"request","version":1,"id":"req-1","module":"power","method":"start","args":[25]}
```

`version` 省略时兼容旧 envelope，未知版本拒绝。入口校验 ID、模块、方法、JSON 深度、参数数量和消息体积；模块再校验方法参数及 manifest 权限。每个 frame 每秒最多 60 个请求、最多 16 个并发，相同进行中 ID 不重复执行。卸载 frame 时中止网络请求、不再回传迟到结果；已经开始的其他 IO 不保证回滚。

原生电源会话 token 只存在宿主闭包中，不进入 iframe、ready payload、store 或日志。`power` 模块只有三个方法：

| 方法 | 参数 | 行为 |
| --- | --- | --- |
| `status` | 无 | 查询 supported / active / endsAt |
| `start` | 整数分钟 1–480 | 创建限时断言；运行中重复调用不延长计时 |
| `stop` | 无 | 释放当前断言 |

ready 事件包含当前语言和 `bridgeVersion: 1`。插件轮询状态仅用于显示，页面隐藏时停止轮询；断言到期不依赖前端计时器。错误返回稳定代码及可重试的中英文提示，不回传原生错误详情或路径。

## Rust 服务边界

- `open_widget_power_session`：仅 main，验证内置安装内容，生成 32 字节随机 token；替换会话前先释放旧断言。
- `widget_power_request`：仅 main，校验 token、枚举动作及分钟范围。
- `close_widget_power_session`：仅 main，旧 token 不能关闭替换后的会话。
- `revoke_widget_power`：仅 main/settings，只能撤销固定组件，不能开始运行。关闭开关必须等待撤销成功；失败保持启用并允许重试。

macOS 使用 IOKit `PreventUserIdleSystemSleep` 和系统 `TimeoutActionRelease`。Rust 持有断言，系统负责到期释放，不启动轮询线程。刷新/销毁主页面、覆盖安装和卸载释放会话；进程退出后由系统回收。释放失败保留状态供重试，系统超时仍有效。其他平台返回 unsupported。

该服务防止空闲系统睡眠，不改写系统电源设置、不执行 shell、不需要管理员权限，不承诺合盖保持运行或阻止用户主动睡眠。

## 系统监控

`system.getMetrics()` 返回同一份 `{sampledAt,cpu,memory,battery}` 快照；每项为带 `status` 的 union：`ok`/`warmingUp`/`notPresent`/`unavailable`/`unsupported`，成功值位于 `value`。宿主按 unknown 校验后才回传，不用 0 冒充失败。原生命令 `get_system_info` 仅允许 main，平台查询通过阻塞工作池执行。

所有调用者共享 `MetricsService` 的互斥采样器及 3 秒缓存，无常驻原生 timer、线程、子进程或遥测。可见插件一次请求完成后再等待 3 秒，无重叠；隐藏、页面销毁和停用停止轮询。CPU 使用 Mach tick 差值，首次或间隔超过 30 秒需重新预热，处理 u32 回绕与计数器重置。内存读取真实总量和系统页大小，口径为 active + wired + physical compressor pages，不声称等同活动监视器或可用内存。电池区分无内部电池、读取失败、充电、接电未充电和电池供电。

旧 `getCPUUsage`、`getMemoryInfo`、`getBattery` 均投影自同一快照；旧内存 `free` 字段仅为总量减上述占用的兼容余量。移除原先 shell 输出解析和固定 16KiB 页大小。旧媒体 API 已返回迁移提示，真实控制使用独立音频宿主工具。采样可供声明 `system` 的组件读取，不是防休眠/剪贴板式的固定 ID 可信服务。

## 剪贴板转便签

只允许固定组件 `com.pinwall.clipboard-note` 声明 `clipboard` 并调用无参数 `clipboard.openImport()`；不授予 `cards` 权限。该方法仅打开懒加载的宿主 Radix 弹窗，不触发读取。用户必须点击宿主“读取一次文本”，然后单独点击“创建便签”。原文和编辑内容均不进入 iframe/AI/日志，响应仅为 `{created:false}` 或 `{created:true,cardId}`。没有历史、监控、写剪贴板或自动读权限。普通 store 的 `createCard` 现在返回新 ID，既有 `cards.create` bridge 响应为 `{cardId}`。相邻 widget-sdk 的旧 `Promise<CardData>` 声明未在本轮更新/发布，调用方不能据此期待完整卡片；新增内置工具直接使用本页协议。

`read_widget_clipboard_text` 仅允许 main 和精确匹配内置文件的安装，使用 AppKit NSPasteboard。读取前拒绝 `ConcealedType`、`TransientType`、`AutoGeneratedType` 标记，前后检查 changeCount，限制 UTF-8 为 64 KiB，空内容和超限直接拒绝、不截断。未标记的文本无法自动判断是否含敏感信息，确认预览仍由用户决定。

平台读取离开 UI 线程，原生全局最多一项读取；前端 8 秒截止，关闭/销毁弹窗或 frame 时丢弃迟到结果。已开始的系统读取不能强制取消，可能继续占用唯一读取槽位直到系统返回，期间重试会失败并提示。仅成功点击确认后创建普通便签；保存失败保留同一个内存草稿并按相同 ID 重试，不重复创建，退出进程前仍需成功保存。弹窗具有焦点限制、Esc 取消、中英文错误和窄窗口布局。

新增 macOS 直接依赖 `libc`、`core-foundation-sys`、`objc2`、`objc2-app-kit`、`objc2-foundation`，均为已有锁定版本；未新增 Tauri capability，未改变持久化 schema。自动化剪贴板 smoke 只使用私有命名 pasteboard，不读写用户通用剪贴板。

## 图片识字与图片处理

新增独立高风险权限 `ocr`、`images`，只允许各自固定 ID `com.pinwall.ocr-note`、`com.pinwall.image-tools` 调用无参数 `ocr.open()`、`images.open()`。二者只打开懒加载宿主界面；iframe 收不到路径、图像、识别文字或原生选择 token。OCR 响应仅含创建结果/卡片 ID，图片工具只回传 `{closed:true}`。安装后的 manifest/HTML/icon 必须逐字节匹配内置资源；声明 official 或复制权限不能获得能力。

原生命令均限制 main，阻塞选择器和处理离开 UI 线程：

| 命令 | 宿主输入/输出 | 边界 |
| --- | --- | --- |
| `recognize_widget_image` | 无输入；取消/null 或识别文本 | 选择器由原生打开，Vision accurate 中英文识别，最多 64 KiB UTF-8 |
| `select_widget_image` | 无输入；取消/null 或 token/尺寸/原大小/PNG 缩略图 | 不接受任意文件路径，原图只在原生内存 |
| `export_widget_image` | token + width/height/format/quality；取消/null 或尺寸/字节数/格式 | 系统保存选择器，拒绝原图、符号链接、AppData 及扩展名不符 |
| `revoke_widget_tool` | 固定内置工具 ID 之一；无返回内容 | main/settings 只可清除图像/屏幕选择、停止清空历史或停用暂存架，不能启动 |

图像服务共享单操作槽，拒绝并发 OCR/选择/导出。选择结果只保留一张，10 分钟逻辑过期，关闭图片弹窗、frame 销毁/刷新、停用、卸载、重装或主页面重载清除。选择 token 是宿主内部标识，不充当加密凭证；原生权限和内容校验独立进行。清除使迟到的选择失效；保存前再次确认当前选择。已打开的系统选择器或开始的 Vision 调用不能强制终止，前端取消会丢弃结果，原生槽位等待系统返回。

输入只允许 PNG/JPEG/WebP，按实际内容识别，限制 20 MiB、1600 万像素、8192 单边和 decoder 128 MiB 分配预算，应用 EXIF 方向。输出使用 Lanczos3 缩放、PNG 最佳压缩、WebP 无损和 JPEG 质量 1–100（透明填白），重新编码像素不复制原元数据；体积可能增大。输出通过目标目录内 0600 临时文件、fsync、rename 替换，不修改原图。本图片工具没有 HEIC/PDF、摄像头或批量操作；屏幕捕获由独立授权的屏幕工具提供。Vision 直接链接系统 framework，不启动 Swift helper、不访问网络。

新增 image 0.25.9（仅 png/jpeg/webp）和 base64 0.22；锁文件固定传递依赖，objc2-foundation 启用 NSData/NSDictionary/NSError；没有扩大 Tauri capability 或修改持久化 schema。

## 剪贴板历史

固定 `com.pinwall.clipboard-history` + 独立 `clipboardHistory` 权限。插件只可调用 `clipboardHistory.open()` 和 `clipboardHistory.status()`；后者仅返回 recording/count/revision，不返回文本。全部历史内容、复制、删除和创建便签都在宿主 UI，不能通过 iframe 指定历史 ID 或注入文本写剪贴板。

`widget_history_request` 仅 main + 精确内置内容，接收严格枚举 status/start/pause/clear/delete/copy；额外参数拒绝，运行在 blocking worker。`get_widget_history_status` 仅返回元数据，宿主按 revision 变化取完整快照，避免持续传输最大 1 MiB 文本。界面和插件隐藏时暂停状态查询，但用户明确开始的原生记录继续。

Start 后仅创建一个 native thread，每 750ms 查询 changeCount，只在变化时读取；开始不读取已有文本。与单次导入共享原生读取槽和私密/临时/自动生成标记过滤，单条最多 64 KiB。最多 100 条、合计 1 MiB、24 小时保留，重复文本移到最前；无磁盘写入、无启动恢复。Pause 停止但保留历史，Clear 停止并清空，关闭弹窗继续记录。停用、卸载、覆盖安装、主页面重载/销毁或进程退出清空，重新开启仍须 Start。迟到结果按 generation 丢弃，旧系统 provider 返回前不能再开第二个 worker；失败有重试状态。未标记的敏感文本无法自动过滤，UI 明确提示。

复制只允许宿主按钮写入已选历史文本；转便签复用确认编辑和同 ID 保存重试，不重新读取当前剪贴板。前端完整快照逐项校验类型和大小，没有把文本回传 iframe/AI/日志。

## 文件暂存架（File Shelf）

固定 `com.pinwall.file-shelf` + 独立高风险 `shelf` 权限。iframe 只能调用无参数 `shelf.open()`，返回 `{closed:true}`，不能传入文件路径、读取索引或文件内容。`widget_shelf_request` 只允许 main 和精确内置内容，严格动作 activate/status/add/remove/clear/export/reveal 拒绝额外字段，IO 在 blocking worker 执行。add 使用原生多文件选择器，拖入路径只来自 main 的 Tauri 原生 DragDrop 事件，且仅在宿主暂存架弹窗打开时接受。宿主事件仅传 added/skipped 或错误代码，不传路径。

AppData/native-tools/shelf.json 使用 schemaVersion 1，保存引用的本地路径、文件名、ID、加入/过期时间及 Unix device/inode；路径不进入 iframe/日志。目录 0700，索引沿用原子替换。最多 50 项、单文件 100 MiB、7 天保留，按打开/操作逻辑清理，无后台计时器。导入不复制内容、不移动原文件；只接受普通文件、按 canonical 路径去重，拒绝目录和末级符号链接。使用前复核路径、文件身份和限额，缺失/替换显示不可用；不提供文件备份、拖出或执行，使用 Finder 定位或另存副本。

关闭/停用/重装/页面重载使 generation 失效并停止接收拖入，保存引用保留；卸载删除索引及其损坏备份，不删除原文件。未来 schema 原样保留并提示升级，损坏索引保留 `.corrupt-backup`，需宿主明确确认清空后才能重置。原生 IO 槽使用 try_lock，繁忙直接提示，不排队累积；慢文件提供者的已开始 IO 仍可能等待系统返回，生命周期锁不跨此 IO 持有。

另存副本通过系统保存窗口，不接受 JS 目标路径；拒绝 AppData、符号链接及覆盖所有已引用原文件。以 64 KiB 分块、0600 同目录临时文件、flush/fsync/rename 导出，逐块及替换前检查撤销，失败清理半成品并保留原目标。已经完成的原子替换不回滚。Finder 定位只揭示文件，不执行文件。

## 屏幕工具（Screen Tools）

固定 `com.pinwall.screen-tools` + 独立高风险 `screenCapture` 权限。iframe 仅能无参数 `screen.open()` 并收到 `{closed:true}`，拿不到截图、OCR 正文、色值、路径或 token。`widget_screen_request` 仅 main + 精确内置内容，动作 capture/ocr/color/export 严格校验。与原图片/OCR服务共享单操作槽，拒绝并发处理；没有通用 shell 或任意命令接口。

用户点击宿主“截取屏幕区域”才调用 CoreGraphics preflight/request 屏幕权限，临时隐藏便签墙，等待合成后通过固定 `/usr/sbin/screencapture -i -s -x -t png` 交互选区。Esc 取消；最长 120 秒，关闭/停用/页面重载/退出会终止并回收截图子进程，通常恢复便签墙及焦点，退出不重新显示窗口。macOS 权限拒绝有重试提示；系统首次授权可能需要重启应用。仅 macOS 可用，不含录屏、音频、全局热键截图或自动捕获。

截图短暂写入 AppData/native-tools/capture-cache 的独立 0700 目录，正常路径用 RAII 清理；异常终止可能遗留文件，下次截图会清理旧缓存。输入限制 20 MiB、1600 万像素、单边 8192、decoder 128 MiB；原图仅保留一张、10 分钟逻辑过期，关闭/停用/卸载/重装/重载/退出清除。不要将“本地处理”理解为截图从不落临时磁盘。

OCR 复用本地 Vision、64 KiB 正文上限，结果进入宿主确认编辑弹窗，确认前不建卡、不调用 AI。取色把预览位置映射到原始像素坐标，支持键盘输入，复制仅由宿主按钮写入计算出的 `#RRGGBB`。PNG 导出经原生保存窗口，拒绝 AppData/符号链接/非 PNG 扩展名，复核 token/期限/generation，再用可取消原子导出；不复制原始元数据。关闭会丢弃迟到识别/选区结果，已开始的 Vision/系统文件窗口可能需等待系统返回。

## 扩展顺序与未完成范围

后续能力应按“单独 manifest 权限 → 类型化 bridge → 最小原生命令 → 可撤销生命周期 → 错误/离线状态 → 测试和原生 QA”逐个加入。以后新增能力同样需要独立评估读写范围与资源预算，不能通过通用 shell 权限接入。

本轮不提供第三方原生插件执行或开放市场服务。已补齐本地包更新/回滚、旧插件数据迁移、原生网络代理和资源 scope；仍需真实生产运行与独立安全审查，不把这些改造当作完整安全认证。iframe 改造和少量可信原生服务不等同于整个 Widget 体系已完成安全化。

系统 Dock 悬停预览、全局输入/文本展开、风扇等硬件控制、视频处理、录屏和应用卸载仍未实现，继续按原方案推进。音频路由、窗口布局/切换/按需窗口预览的实现及尚未执行的原生验收见下节。

## 本地工具与插件仓库（2026-10-27 续）

固定 `com.pinwall.local-tools` + 高风险 `utilities` 权限；iframe 只能 `utilities.open()`，不能传入待复制文字或读取片段。宿主 `widget_utilities_request` 严格枚举 list/save/remove/clear/copy。链接/计算在宿主离线纯函数完成，不使用 eval、网络或全局输入。链接仅删已知追踪参数，检测已知签名/token 参数则保留原链接；不能识别所有自定义签名，结果需用户审阅。计算器支持基础运算、幂、弧度三角函数等单参函数，512 字符/256 token/32 层括号/有限浮点结果，非财务精确计算。

片段仅在 AppData/native-tools/snippets.json，经版本化原生数据事务持久化；100 条、标题 256 字节、正文 64 KiB、总量 1 MiB。只在明确点击 Copy 后写入文本，不读剪贴板。关闭/停用保留片段，卸载清理片段及损坏备份。发起后已开始的保存可完成；关闭丢弃迟到 UI 结果。

包安装限制 32 MiB、256 个文件/目录、12 层、入口/图标 2 MiB、manifest 64 KiB，拒绝符号链接与特殊文件。先复制到私有 staging，完整验证后切换；先前版本保留在隐藏 previous 目录。切换失败恢复旧版，启动列表补偿中断；备份目录不作为插件渲染。本地安装先原生预览，确认 ID/版本/权限后安装，再次校验；回滚也审阅权限、默认停用，不降级数据。当前为同进程事务，不承诺不同应用进程同时修改同一 AppData 的事务隔离。

插件 storage 使用 schemaVersion 1 + revision + data，兼容旧裸 map，在首次成功修改时迁移。只允许已安装且声明 storage 的 main 调用；mutate 原生串行读改写，避免前端 read-modify-write 覆盖，失败原子保留，损坏备份并拒绝继续写入，未来版本不覆盖；1 MiB/256 键/20 层上限。回滚不回滚数据，旧版应用需遵守未来 schema 拒绝策略。损坏数据无自动重置入口，需从已知有效备份恢复，不能通过 clear 静默覆盖。

network bridge 统一走 main 原生 `widget_network_request`，验证已安装 manifest 的 network 权限。仅 HTTP(S)、80/443、无 URL 账户密码/fragment；DNS 最长 3 秒，所有地址都须公网，固定解析地址连接，禁环境代理/重定向/隐式凭据；每请求 15 秒、原生总并发 8/每插件 2、输入输出 JSON 各 1 MiB。只保留 accept/content-type/accept-language/x-widget 等少量头；响应不回传完整错误、URL 或路径。关闭 frame 发送取消并丢弃迟到结果；JSON 之外资源不走此接口。资源协议从整个 AppData 收窄为 backgrounds/**，iframe 仍只接受 inline/data/blob 资源。

这些约束不等于允许任意第三方原生执行；原方案剩余项与外部依赖见 `PLUGIN_ROADMAP.md`。


## 音频、窗口与桥接实际执行（2026-10-27）

官方目录十四项、可选原生工具十一项。音乐保留 `com.pinwall.music` 升级 2.0，改为 desktop 内置资源和高风险 `audio` 权限，旧版重新安装。`com.pinwall.window-tools` 使用独立高风险 `windows` 权限。iframe 只能打开宿主面板，无法获得设备标识、进程、窗口标题、token 或图像。所有 native request 仅 main，精确资源字节校验；设置窗口只允许撤销。原生实现由 build.rs/cc 编译 Objective-C，链接公开系统 API，ScreenCaptureKit/UserNotifications 弱链接并按系统版本判断。

音频设备：CoreAudio 按需枚举输入/输出、设置默认设备、音量/静音；无主音量时读取首选立体声通道，保留通道比例写入，部分失败尝试恢复。设备只读/断开可处理。明确设置的系统偏好关闭后保留。媒体只控制已经运行的 Music/Spotify，通过固定 Apple Events 脚本读取真实信息和执行固定播放动作，最长脚本超时 5 秒；不启动播放器、不接受任意脚本。新增 `NSAppleEventsUsageDescription`、`NSAudioCaptureUsageDescription` 与 hardened runtime Apple Events entitlement；不扩大 Tauri capability。自动化授权仍由 macOS 按目标应用决定。

每应用路由：macOS 14.2+，显式选择一个正在输出的 CoreAudio process/PID 和设备；最多 4 路，每进程一路、增益 0–100%。进程 tap/私有 aggregate 仅含所选进程，无麦克风子设备；独立 HAL 输出，float32 stereo、8–192 kHz，受限线性采样率转换。每路 65536 帧 stereo 环形内存，实时回调不分配/加锁/写盘/调用 ObjC；欠载填静音、超限丢帧，宿主显示计数。先建立输入/输出，最后才静音原路径；停止先尝试恢复原路径，再销毁输出/tap。驱动拒绝释放时保留回调内存避免 UAF，报 cleanup 失败并由 watchdog 重试，必要时退出应用。1 秒 watchdog 仅有活动资源时存在，检查进程/设备/采样率和无数据流；5 次连续无数据则停止。关闭、停用、卸载、重载和退出清理；隐藏页面停止。迟到启动使用原生 epoch 拒绝。实际音频流/TCC/设备稳定性当前仅列人工验收，不能用 DSP/浏览器模拟宣称通过。

窗口：Accessibility 主动授权入口；最多 64 个普通应用、128 个窗口、3 秒枚举预算、单 AX 消息 150 ms 超时，排除 PinWall。宿主 token 绑定原始 AX 元素；过期拒绝。使用显示器 visibleFrame 转 AX 坐标，支持负坐标、左右/上下/四角、居中与填充；应用尺寸限制会提示，变更失败尝试恢复。保留本次原布局，可明确恢复；刷新复用同一 AX 元素 token，关闭释放。切换仅激活所选应用并 raise 窗口。macOS 14+ 使用 ScreenCaptureKit 按需缩略图，480×最多320像素，PNG≤700 KiB；每次异步等待≤6秒。标题/像素仅宿主，完成后迟到结果丢弃，不持久化；这不是系统 Dock 的悬停预览。

桥接：`settings.get/getAll` 读取当前组件设置，更新值不重建 frame 会话；插件只可 emit `widget:<自身ID>:` 命名空间，不能伪造 ready/核心事件。`notify.send` 验证安装包 notify 权限、标题≤512 B/正文≤8192 B，原生每插件 5 秒限流，首次可能请求系统通知授权；返回 submitted 仅表示 macOS 接受，最终展示受通知设置/专注模式影响，拒绝/超时有错误。通知独立于核心提醒 store，不覆盖便签提醒。旧 `system.getMediaInfo/mediaControl` 返回 `media_use_audio_tool`，不再伪造曲目/成功；需重新安装新的音乐组件。

## 输入增强

`com.pinwall.input-tools` / `input` 为固定可信源，默认关闭。`widget_input_request` 仅 main，动作枚举为 load/save/status/permission/start/stop，不接收脚本或事件注入参数。规则保存在 AppData/native-tools/input-tools.json，版本化、原子写、损坏备份、未来版本拒写；停用保留、卸载删除。100 个应用排除项、50 个唯一规则，触发词为分号加 1–23 个 ASCII 字母数字/下划线/连字符，替换最多 256 UTF-16 单元。

主动开始才注册 CGEventTap 和应用激活观察；无自动启动。滚轮可仅作用于离散鼠标，Option+H/J/K/L 配对修改 keydown/up。文本展开只保留分号开始的 24 字节候选、2 秒超时，不读取 AXValue、不持久化/返回/记录输入。安全输入、密码框、非 ASCII 输入法、PinWall 和排除应用跳过展开；默认排除终端/密码管理器。空格触发展开，Cmd+Option+Z 在 5 秒内同进程/焦点且无其他输入时撤销；合成输入兼容性需实机验收。事件 tap 被系统停用会释放并提示，不自动重启。

关闭面板/隐藏墙保留显式启动的服务，Stop、撤销、停用、卸载、墙重载和退出清理。主机 epoch 拒绝撤销后排队启动。状态轮询仅活动面板可见时每 2 秒，关闭释放前端轮询；未捕获任何真实输入进行自动化测试。

## Dock 悬停预览

窗口宿主新增 dockStart/dockStop/dockStatus。macOS 14+、用户主动开启且已有辅助功能/屏幕权限时，每 250ms 检查指针是否位于系统 Dock 窗口；仅此时读取 AXDockItem 的本地 bundle URL，精确匹配正在运行的普通应用，不打开 URL。悬停 350ms 后用 ScreenCaptureKit 截取最多四个可见窗口的 400×240 缩略图；无文件和插件图像接口。系统内容枚举最多一个未完成请求、图像最多四个未完成请求，跨旧会话保持预算；epoch 拒绝迟到 UI。原生非激活面板按当前显示器 visibleFrame 定位，点击前复核 PID/窗口 ID 与 AX bounds 后 raise。

关闭宿主面板只释放窗口列表/撤销引用，已开启的 Dock 服务继续；隐藏墙、睡眠、权限失效、停用、卸载、重载或退出停止计时器并销毁面板。未开启时无轮询。自动化只测负坐标几何/控件流程，不启动真实 Dock 监听或捕获。

## 视频与录屏

`com.pinwall.video-tools` / `video` 默认关闭，仅主宿主枚举 DTO。插件只能打开面板，不能提交路径/编码命令。原生选择 MP4/MOV/M4V 后复制到 AppData 私有工作目录（512 MiB、30 分钟、1600 万像素、120fps 上限），AVURLAsset 禁止所有外部媒体引用；受保护或多个视频轨拒绝。输入快照与 token 最多十分钟有效。裁剪 0.1–600 秒、480/720/1080p 上限、保留或移除音轨、MP4/MOV 导出；AVFoundation 去除导出元数据，十分钟截止、取消及单操作预算。先编码私有临时输出，再可取消原子写到用户明确选择的位置，拒绝覆盖原视频与 AppData，失败保留输入和原目标。

录屏只在 Start 后调用固定系统 screencapture，录制主显示器、无麦克风/系统音频、1–300 秒、512 MiB；不接受自定义参数。Stop 以 SIGINT 请求完成并等待最多十秒，Cancel/关闭/停用/重载/隐藏墙/退出终止回收，generation 拒绝排队启动。录制完成后选择保存原始 MOV 或再裁剪导出，关闭丢弃未保存结果。临时目录下次使用清理崩溃遗留。AVFoundation 取消后若系统回调未结束，保留繁忙门槛防止无限积压编码任务。

Objective-C 原生比较结果显式转 BOOL，保证 JSON 输出真正布尔值；真实合成视频和只读设备 smoke 检查该边界。仓库安装/列举清理已退出进程的 .stage-PID-sequence，保留当前/存活进程工作，不跟随链接；独立安全审计仍待执行。

## 系统维护

`com.pinwall.maintenance` / `maintenance`，默认关闭，仅固定可信资源和主宿主可调用。没有自动扫描、永久删除、任意路径/PID/命令接口或管理员权限。原生串行队列在工作线程枚举和 IO，不阻塞主窗口线程。目录、操作预览和进程以会话 token 标识，两分钟有效；执行前复核文件设备/inode 或进程 UID/PID/开始时间/可执行路径。撤销递增 epoch，排队工作拒绝；已开始的移动、信号或软件包脚本不能承诺回滚。

- 应用仅 /Applications 和 ~/Applications 的普通非 Apple、非 PinWall 包；正在运行的应用拒绝卸载。默认只处理所选应用包，同 bundle ID 的 ~/Library/Caches 与 ~/Library/Preferences/name.plist 分别明确勾选。缓存仅用户 Caches 顶层，排除 Apple/PinWall。拒绝入口 symlink/越界，体积估算不跟随内部链接，每个目标最多 20,000 项/一秒，估算不完整会标记。
- 仅调用系统 Trash API，最多三项目标。部分成功同样保留恢复记录；会话最多二十批，恢复不覆盖重新创建的原位置、不跟随变化的废纸篓项目。重启后依靠 Finder Trash 恢复；卸载插件清除内存预览/恢复记录，废纸篓内文件保持。无额外持久化 schema。
- 进程只列举当前 UID 的非系统可执行程序，排除 PID 1、自身与 PinWall 包内进程及系统目录；最多 250 项。不暴露命令行参数。预览默认为 SIGTERM，SIGKILL 需单独选择并确认。成功只指 signal 已提交，需刷新确认退出，不声称可恢复未保存状态。
- Homebrew 只识别标准 canonical executable，固定 list --formula --versions / uninstall --formula name，不接收 shell、任意 brew 参数、cask、安装或更新。关闭自动更新/分析/清理和 stdin；进程组受控，输出最多 1 MiB、formula 最多千项、120 秒截止。卸载预览绑定实际 formula、版本及程序位置，执行前重新列举复核；依赖失败不加 --force。Homebrew 可能运行已安装包的卸载脚本，失败/取消需人工核对软件包状态。

自动化只使用临时目录和链接验证扫描/身份边界，浏览器使用合成 IPC；没有移动真实应用/缓存、发送真实进程信号或执行 Homebrew 卸载。

macOS 仓库安装/读取/恢复在进程内 mutex 外增加包级文件锁；版本化数据事务在加载前获取独立文件锁，两个 app 进程不会并发读取同一旧 revision 再覆盖。锁使用 O_NOFOLLOW、非阻塞 flock，繁忙明确失败，空锁文件保留以维持协调 inode；不保存用户数据。它不构成独立安全审计，其他平台与实机资源/性能仍按原计划验收。


第三方可信市场（P2、默认关闭）：根签审核目录 + 发布者签名包，手动刷新/权限审阅/默认关闭安装及更新；离线审核工具与只读源站见 [MARKETPLACE_TRUST.md](./MARKETPLACE_TRUST.md)。公网域名/TLS/真实信任根需发行者配置；不支持任意匿名代码或进程级 CPU 隔离，统一原生验收保持未勾选。


## EDR 与签名硬件助手

新增固定 `com.pinwall.display-tools` / `display` 与 `com.pinwall.hardware-tools` / `hardware`，默认关闭。iframe仅能无参打开宿主面板，不能提交屏幕采集、RPM、路径或SMC键。Rust按main、精确内置资源及严格枚举DTO校验，原生epoch拒绝撤销后的排队动作；清理接入面板/隐藏墙/停用/卸载/重装/重载/退出。

Tauri capability未扩大；root日志是已批准helper独占的版本化恢复记录，不授予Web插件root或文件权限。源码复核见 [PLUGIN_SECURITY_REVIEW.md](./PLUGIN_SECURITY_REVIEW.md)，页面基线和真实性能待填表见 [PLUGIN_PERFORMANCE.md](./PLUGIN_PERFORMANCE.md)。
