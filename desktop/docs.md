## PinWall — 把便签贴满你的桌面，一个开源的桌面便签墙应用

大家好，分享一个自己做的开源桌面小工具 **PinWall**，一个可以钉在桌面上的便签墙应用。

### 是什么？

PinWall 是一个基于 **Tauri 2 + React 19** 的桌面便签应用。它的核心理念是：**把你的桌面变成一面便签墙**。便签可以随意拖拽、自由摆放，就像在真实桌面上贴满便利贴一样。

### 主要功能

- **自由摆放**：便签可以在桌面上任意拖拽定位，想放哪就放哪
- **多彩渐变卡片**：8 种精心搭配的渐变色，每张便签都有自己的颜值
- **窗口控制**：每张便签都有类似 macOS 窗口的关闭/最小化/最大化按钮
- **便签提醒**：支持设置提醒时间，到时会在桌面右上角弹出通知
- **卡片堆叠收纳**：暂时不用的便签可以收纳成堆叠卡片，桌面不杂乱
- **自定义壁纸背景**：支持设置背景图 + 透明度 + 自动轮播
- **透明无边框窗口**：全屏透明窗口，便签直接浮在桌面上
- **快捷键**：`Cmd+Shift+N` 快速创建新便签
- **数据本地持久化**：所有数据保存在本地，不上传云端，隐私无忧

### 为什么做这个？

用过很多便签应用，要么太重（Notion、Obsidian），要么就是简单的列表形式。我想要的就是一个**打开就能看到、随手就能贴一张**的东西，像真实的便利贴一样。PinWall 没有文件夹、没有标签系统、没有复杂的组织方式——它就是一面墙，你把想法钉上去就好。

### 技术栈

| 层 | 技术 |
|---|---|
| 桌面框架 | Tauri 2 (Rust) |
| 前端 | React 19 + TypeScript |
| 构建 | Vite 7 |
| 状态管理 | Zustand 5 (跨窗口共享) |
| 数据存储 | 本地 JSON (tauri-store) |

整个应用安装包很小，启动很快，内存占用也很低。
