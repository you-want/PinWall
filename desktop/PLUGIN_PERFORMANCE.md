# 插件性能基线与原生验收

## 可重复的浏览器基线

2026-10-27，macOS x86_64、本机 Chromium、Vite 开发模式和隔离合成 IPC。预热模块后，三场景交替运行五轮，每轮空闲观察 1500ms，再以 30 个真实鼠标移动步骤拖动卡片。数据只涉及合成卡片和受控启动页，不采集真实屏幕、音频或输入。

固定 1600×1000、12 张存储卡片（11 便签 + 1 喝水卡）。**现有产品 `useCards` 固定只显示五张，其余七张收纳**，本轮未修改此核心规则；不能据此宣称同时渲染/拖拽 12 张通过。已有提醒/系统调度保持真实 React 实现，所有 native IPC 使用测试替身。

| 场景 | 暖导航到界面就绪中位数 ms | 1500ms 空闲内 renderer TaskDuration 中位数 ms | JS heap 中位数 MiB | 拖拽帧间隔 P95 的中位数 ms |
| --- | ---: | ---: | ---: | ---: |
| 无插件 | 484.4 | 0.935 | 18.61 | 16.7 |
| 16 个原生插件已安装/全部停用 | 506.8 | 0.915 | 20.14 | 16.7 |
| 同上，只启用本地工具启动卡片，未打开工具 | 659.4 | 0.866 | 15.37 | 16.7 |

所有十五次空闲窗口均没有 widget/native-tool 读写调用。停用场景启动中位数增加约22ms；启用启动卡片还包含 iframe 初始化/120ms ready 协议。堆内存受 GC 影响，较低值不表示启用插件节约内存。TaskDuration 是 CDP renderer task 时间，**不是进程 CPU 百分比、系统唤醒次数、RSS 或 GPU/能耗**；这里只形成页面参考，未据此设定原生性能门槛。

复现：安装 Playwright Chromium 后执行 `pnpm test:performance`。`playwright.performance.config.ts` 使用单 worker，`e2e/plugin-performance.bench.ts` 保留所有原始样本并作为 JSON 附件、在控制台输出汇总；可加 `--reporter=html` 留存报告。测试只对流程/零后台调用作断言，不以单机时间放宽功能测试或硬设跨机器指标。正确性全量测试另用 `pnpm test:e2e`，不受此基线配置影响。

## 真实 macOS 最终验收

尚未测量，不预填数值；与统一验收一起完成。使用相同签名、相同设备/系统/电源/屏幕亮度/窗口状态，每个场景先稳定两分钟，再采样五分钟；活跃工具和长期稳定性另连续观察三十分钟。记录宿主、WKWebView/WebContent、GPU 与可选 helper，避免只看主进程。Intel/Apple Silicon 分别记录，不混合比较。

| 场景 | 冷启动/可编辑时间 | CPU/RSS/唤醒/能耗 | 停止后资源 | 结果 |
| --- | --- | --- | --- | --- |
| 无插件、12张存储卡片 | 待测 | 待测 | 五可见/七收纳 | 待验收 |
| 全部原生插件停用 | 待测 | 与同机基线比较 | 无采样、tap、流、捕获、维护命令 | 待验收 |
| 只启用监控 | 待测 | 3秒采样，隐藏停止 | 关闭/停用后无前端轮询 | 待验收 |
| 历史/输入/Dock分别主动开启 | 待测 | 各自预算与30分钟稳定性 | 停用/重载/退出后释放 | 待验收 |
| 音频路由/视频/EDR分别开启 | 待测 | CPU、音质/丢帧、GPU和温度 | 实际停止确认、无积压任务 | 待验收 |
| 已批准硬件helper | 待测 | 空闲无定时采样；活动1Hz watchdog | ≤5秒失联恢复；日志恢复失败重试 | 待验收 |

记录每次同机差值及测量误差后确定该设备的预算；空闲停用不应产生插件持续调用、后台队列增长或新增常驻采样。活动工具的合理开销取决于编码、屏幕与设备，发生持续增长、停止后资源不回落、拖动/编辑受阻或热压力未停止即阻断。需要同时显示10+卡片的性能要求受当前五张可见的产品规则限制，若后续取消该限制，应另测并设预算，不能用存储数量替代渲染数量。

不要在真实个人数据上自动开启输入、录音/录屏、硬件或维护功能来采样。本轮没有执行上述原生场景，页面结果不能替代它们。
