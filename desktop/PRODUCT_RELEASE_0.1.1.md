# PinWall Desktop 0.1.1 产品发布文档

## 发布定位

`0.1.1` 是 `0.1.0` 之后的补丁版本，目标不是扩功能，而是修复桌面端核心交互问题，让透明桌面便签体验更稳定。

本版本继续以 macOS 桌面端为主线，Web 端仍作为历史 demo / 辅助入口。

## 一句话介绍

PinWall 是一款直接贴在 macOS 桌面上的透明便签墙应用，适合把临时想法、待办提醒和轻量信息卡片放在最容易看见的位置。

## 本次发布重点

- 修复新建便签弹框的底部按钮和颜色提示重叠问题。
- 修复新建便签弹框中类型选择被挤出或隐藏的问题。
- 修复桌面底层时点击便签、按钮、卡片被穿透的问题。
- 修复护眼、休息、下班、天气、心情打卡等关怀卡片重复出现的问题。
- 修复快速创建卡片时潜在的 ID 冲突。
- 加强本地 Widget 安装校验和网络权限边界。
- 设置页展示 Widget 权限，并突出网络、系统、便签、AI 等高风险权限。

## 面向用户的更新说明

### 改进

- 新建便签弹框更稳：类型选择、颜色选择、按钮区域在不同窗口尺寸下更不容易溢出。
- 桌面交互更符合预期：只有点击空白区域才会退到底层，点击便签、按钮和弹框不会穿透。
- 自动关怀卡片更克制：同一种提醒只保留一张卡片，后续提醒会更新已有卡片，而不是不断铺满桌面。
- 本地 Widget 更安全：增加 manifest 校验、路径校验、符号链接拒绝、网络请求限制和权限展示。

### 修复

- 修复颜色未选择提示文字与取消/创建按钮重叠。
- 修复便签类型选择区域内容被裁切。
- 修复底层模式下交互元素误穿透。
- 修复护眼提醒等自动卡片重复创建。
- 修复快速创建卡片时可能出现重复 ID。

## 下载方式

发布地址：

https://github.com/you-want/PinWall/releases

- `PinWall-universal.dmg`

该文件适用于 Apple Silicon 和 Intel Mac。

## 安装提示

1. 下载 `PinWall-universal.dmg`。
2. 打开 DMG。
3. 将 `PinWall.app` 拖入 Applications。
4. 从 Applications 启动 PinWall。

如果 macOS 提示来自未知开发者，需要在系统设置中允许打开。后续版本应考虑签名和 notarization。

## 发布前检查

自动检查：

```bash
cd desktop
pnpm test:run
pnpm build
cd src-tauri
cargo test
```

打包检查：

```bash
cd desktop
pnpm tauri:build:app
```

手动检查：

- 新建便签弹框布局正常。
- 便签、按钮、Widget、弹框都不会误穿透。
- 点击空白区域会退到底层。
- 护眼/休息等自动卡片不会重复堆积。
- 设置窗口可打开，Widget 权限展示正常。
- 重启后已有便签数据保留。

完整 QA 清单见 `RELEASE_QA.md`。

## 已知限制

- 当前主要支持 macOS。
- Widget Marketplace 和开发者门户仍是实验方向，不作为稳定功能宣传。
- 本地 Widget 仍建议只安装可信来源。
- 如未完成 Apple 签名和 notarization，macOS 可能出现安全提示。
