# PinWall Desktop

> macOS 桌面上的透明便签墙与轻量工作台。

PinWall Desktop 是当前产品主线。它基于 Tauri v2 构建，目标是把便签、提醒和轻量信息卡片直接放在桌面壁纸上，同时尽量不打扰正常桌面操作。

Web 端目前仅作为历史 demo 和辅助入口，不作为当前产品主线。

```bash

# 运行单元测试

# 构建发布版
```

## 便签编辑与布局恢复

点击便签标题栏的编辑图标，或从右键菜单选择“编辑便签”，可修改标题、正文和颜色；提醒便签还可以调整提醒时间或关闭提醒。`Cmd/Ctrl+Enter` 保存，`Esc` 取消。编辑保留便签类型和打卡记录。

应用启动时保留已保存的卡片位置；右下角“整理排列”按钮仍可主动排列。所有本地 store 加载完成后才启动页面；加载失败时显示重试提示。

浏览器 E2E 使用独立的 `1932` 端口和测试专用 Tauri IPC 适配器，真实 React/Zustand 逻辑仍会运行，持久化只写入隔离浏览器上下文的 localStorage。它验证 UI、启动和重新加载流程，不代替原生 AppData、多窗口同步、窗口穿透及真正退出重启的验收。日常运行使用 `pnpm tauri dev`。

## 设置事务与便签备份

设置通过原生 revision 事务更新，避免多窗口修改不同字段时互相覆盖。设置和卡片带有 schema version；启动时检查版本和字段，旧卡片迁移保留布局。损坏数据会保留原文件及同目录 `.corrupt-backup` 副本并停止启动，未来版本提示升级，不再静默使用默认值覆盖数据。

在“设置 → 基础 → 便签备份”导出 JSON，或选择备份后确认合并恢复。备份包含便签正文、位置和提醒信息，请妥善保存；不包含设置、API 密钥及组件。同 ID 的本地便签优先，导入提醒默认关闭，重复导入不会重复创建。恢复前会在卡片文件旁保存 `.before-restore` 快照。文件上限 20 MiB、10,000 张卡片。

便签的日常保存、迁移和恢复统一经过原生原子替换。窗口只提交改动的卡片字段；原生串行合并并广播最新状态，避免整份旧快照覆盖其他窗口更新。连续拖拽会合并尚未发送的修改。保存失败时保留最后成功保存的文件和当前窗口草稿，并显示“重试保存”；此时请保持应用打开，草稿尚未写入磁盘。

macOS 的 AI / 额度监控 API 密钥保存到系统 Keychain。旧明文密钥在首次成功读取设置时迁移：先写入并验证新的 Keychain 条目，再原子提交仅含引用的设置文件（schema version 2）。权限拒绝、钥匙串锁定或文件提交失败时保留旧数据并提示重试。便签启动预检不读取 Keychain；通知窗口只取得去除密钥的设置。其他平台暂不支持保存 API 密钥。历史副本或外部备份可能仍含旧明文密钥，不会被自动改写。

其他五个 store 仍使用 tauri-store，其版本迁移/备份和损坏文件应用内修复向导留待后续迭代。开发构建的卡片文件仍为 AppData 下 `tauri-plugin-zustand/cards.dev.json`，发布构建为 `cards.json`；卡片 schema version 保持 1。

提醒调度由一个可取消的共享心跳统一驱动：便签提醒、喝水、护眼、休息、下班、心情、天气和跨日重置不会各自创建定时器。订阅全部释放后心跳自动停止；回调正在执行时不会并发重入，系统睡眠后会以当前时间重新检查。

## 可选原生插件（实验）

在“设置 → 实验功能 → 官方组件中心”安装“防休眠 / Keep Awake”，确认 `power` 权限后再打开已安装组件的开关。安装后默认关闭；启用只显示卡片，点击“开始”才会阻止 Mac 空闲休眠。可选择 15、25、60、120 或 480 分钟，也可随时停止。无网络时可用，不需要管理员权限。

此功能属于 P2 可选能力，目前仅支持 macOS。它不阻止合盖或主动睡眠，不保证屏幕常亮；到期由系统释放，刷新、停用、卸载及进程退出也会释放，重启后不会恢复上一次运行。若停止失败，保留启用状态并提示重试。升级后若出现重新安装提示，请从官方组件中心更新组件。

官方组件中心还提供以下默认关闭的工具：

- **系统监控 / System Monitor**：显示真实 CPU、内存和电池状态。可见时每 3 秒刷新，共享原生采样缓存；隐藏/停用后不再轮询。CPU 首次和长时间暂停后显示采样中，内存按活跃、有线及物理压缩页计量，不等同于活动监视器的口径。已有旧版系统监控请点击“重新安装”获取 2.0；覆盖安装后需重新启用。
- **剪贴板转便签 / Clipboard to Note**：打开宿主导入弹窗，点击“读取一次文本”，预览/编辑后再创建普通便签。文本不进入插件 iframe 或 AI；不记录历史、不自动读取。仅支持纯文本，最多 64 KiB；拒绝系统标记为私密、临时或自动生成的内容。保存失败保留草稿，重试不会重复创建；未保存草稿不跨进程恢复。

- **图片识字 / Image to Note**：选择 PNG、JPEG 或 WebP，使用 macOS Vision 在本机识别中英文；预览/编辑文字后再创建便签，取消不创建。图片、识别文字和文件路径不进入插件 iframe 或 AI。
- **图片工具 / Image Tools**：本地调整尺寸、保持比例、JPEG 质量，以及 PNG/JPEG/WebP 转换，使用系统保存窗口导出新文件，拒绝覆盖原图。PNG/WebP 为无损编码，JPEG 透明区域填白；移除原图元数据，输出可能比原图大。输入最多 20 MiB、1600 万像素，单边最多 8192 像素；不支持 HEIC、PDF 或批量处理；截图使用独立屏幕工具。图片识字使用相同输入限制。
- **剪贴板历史 / Clipboard History**：启用后还需点击“开始记录”，只收集之后新复制的纯文本。可搜索、复制、删除、预览后创建便签。仅保存在当前进程内存，最多 100 条、合计 1 MiB、保留 24 小时、单条 64 KiB。暂停保留历史，清空同时暂停；关闭弹窗继续记录，停用/卸载/主页面重载/退出清空且不自动恢复。跳过系统标记为私密、临时或自动生成的内容，但未标记的敏感文本仍可能被记录。

- **文件暂存架 / File Shelf**：从系统选择窗口或 Finder 拖入普通文件，保存最多 50 个文件引用、每个不超过 100 MiB，跨重启保留 7 天。可搜索、在 Finder 定位、另存副本和移除引用；不移动、复制导入或删除原文件。关闭弹窗后不接收拖入，停用保留引用，卸载清除引用；原文件被移动/替换后可能不可用，不属于备份。
- **屏幕工具 / Screen Tools**：点击后申请 macOS 屏幕录制权限并交互选择区域；可本地 OCR、预览编辑后转便签、按原始像素取色/复制色值，以及导出 PNG。选区时暂时隐藏便签墙，Esc 取消；不录屏、不自动截图。截图在私有临时目录处理，正常完成清理；当前选图最多保留 10 分钟，关闭/停用/退出清除。

- **本地工具 / Local Tools**：离线链接跟踪参数清理、受限算式解析器和文本片段库；片段最多 100 条、单项 64 KiB、合计 1 MiB，搜索/编辑/删除及主动复制。不读取剪贴板、不监听全局输入；停用保留片段，卸载清除。

“音频与媒体 / Audio & Media”升级原音乐组件（保留 ID、版本 2.0、需重新安装并启用），提供输入/输出设备、音量、静音和运行中的 Music/Spotify 控制。macOS 14.2+ 可主动路由所选音频进程，最多 4 路独立增益；声音仅在内存处理，关闭/停用停止，实际可用性需权限和设备验收。“窗口工具 / Window Tools”提供辅助功能授权后的布局、跨显示器移动、切换、恢复原布局，以及 macOS 14+ 按需单窗口预览；不操作 PinWall 窗口。

官方目录共 14 项。安装更新先完整校验暂存包，失败保留旧版；已安装行可审阅权限后回滚上一版，回滚后停用，数据不降级。高级本地安装同样先预览权限。

十一项工具均可离线使用，目前主要面向 macOS；实际系统授权、窗口和睡眠唤醒仍需按发布 QA 验收。完整的手工操作步骤见 [PLUGIN_ACCEPTANCE.md](./PLUGIN_ACCEPTANCE.md)，当前均待人工执行。本轮独立实现这些能力，没有复制 Vorssaint 的 GPL 源码。插件协议、原生权限边界和后续扩展约束见 [NATIVE_PLUGINS.md](./NATIVE_PLUGINS.md)。核心便签无需安装或启用插件。

## 技术栈

- **前端**: React 19 + TypeScript + Vite
- **状态管理**: Zustand + tauri-store
- **桌面框架**: Tauri v2 (Rust)
- **本地存储**: 原生便签/设置事务 + macOS Keychain；其他 store 使用 tauri-store，tauri-plugin-fs 用于受控资源 IO

## 产品主线

当前阶段优先级：

1. 稳定透明桌面便签、拖拽、提醒、收纳和本地持久化。
2. 打磨 macOS 桌面体验：点击穿透、托盘、快捷键、重启恢复。
3. 将健康提醒、背景、自定义外观作为增强能力。
4. Widget、Marketplace、开发者门户先作为实验方向，不抢占 0.1 主线。

具体开发约定与生产化优先级见 [AGENTS.md](./AGENTS.md)。

## 项目结构

```
desktop/
├── src/                  # React 前端
│   ├── components/       #   UI 组件（PinCard, PinBoard, CardStack...）
│   ├── pages/            #   页面（Wall, Settings, Notification）
│   ├── hooks/            #   自定义 Hooks（useCards, useReminders）
│   ├── stores/           #   Zustand Store（跨窗口共享）
│   ├── services/         #   本地存储服务
│   └── types/            #   TypeScript 类型
├── src-tauri/            # Rust 原生层
│   ├── src/              #   Rust 源码（窗口管理、穿透、托盘）
│   ├── capabilities/     #   Tauri 权限声明
│   └── tauri.conf.json   #   Tauri 配置
└── package.json
```
