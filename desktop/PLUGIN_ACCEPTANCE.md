# 原生插件统一验收清单

本单覆盖本轮规划的十四项 P2 可选工具：防休眠、系统监控、剪贴板转便签、图片识字、图片工具、剪贴板历史、文件暂存架、屏幕工具、本地工具、音频与媒体、窗口工具、输入增强、视频与录屏、系统维护。代码和自动化检查先完成，下面的人工项按要求留到最后执行，当前均未勾选。原始方案的剩余能力仍在继续开发，完整队列见 `PLUGIN_ROADMAP.md`；本清单不提前标记未执行的原生结果。

## 1. 准备与安装

- [ ] 记录设备、macOS 版本、CPU 架构、应用版本和提交 SHA；Intel 与 Apple Silicon 分别记录，不用单机结果代替双架构验收。
- [ ] 先在“设置 → 基础 → 便签备份”导出备份。准备不含隐私的中文/英文多行文本、文字图片、透明 PNG、JPEG、WebP、无字图片、损坏图片和超过 20 MiB 的图片。导出测试使用单独文件夹。
- [ ] 启动构建好的 `src-tauri/target/release/bundle/macos/PinWall.app`（本机包为 x86_64、ad-hoc、未公证，不是正式发行包），或者在 `desktop/` 运行 `pnpm tauri dev`。开发版与发布版便签文件不同，勿据此判为数据丢失。
- [ ] 打开“设置 → 实验功能 → 官方组件中心”。预期共 14 项；逐个安装十一项原生工具，核对权限说明，取消授权不安装。原有旧版本出现不匹配提示时，重新安装内置组件。
- [ ] 十一项安装后均关闭；分别手动启用。预期只显示工具卡片，不自动选图、读取文本、创建便签、开始防休眠或记录历史；系统监控启用且可见后才按需采样。

## 2. 防休眠

- [ ] 选择 15 分钟并开始，在终端运行 `pmset -g assertions`，预期出现 `PinWall Keep Awake`；重复开始不延长当前倒计时，停止后断言消失。
- [ ] 运行中分别从卡片菜单停用、独立设置窗口停用、卸载和重新安装。预期断言释放，重新启用保持未运行。停止失败应保留开关并可重试。
- [ ] 运行中从托盘退出，再检查断言并重启。预期无遗留断言，便签恢复，防休眠保持未运行。锁屏、睡眠/唤醒后状态准确；不承诺合盖运行、阻止主动睡眠或保持屏幕常亮。

## 3. 系统监控

- [ ] 查看 CPU、内存、电池。预期 CPU 初次显示采样中，随后变化；长时间隐藏后重新预热。内存口径为 active + wired + physical compressor pages，不要求与活动监视器数值完全相等。
- [ ] 分别检查电池供电、接电、接电未充电；无内置电池设备显示无电池。单项失败不把其他项抹掉，也不用 0 冒充读取成功。
- [ ] 隐藏/显示、停用/启用、卸载和睡眠/唤醒。预期隐藏/停用无前端轮询，恢复无重叠请求，关闭全部工具时空闲 CPU 维持正常。

## 4. 剪贴板转便签

- [ ] 复制测试文本，打开导入窗口。预期打开不读取，点击“读取一次文本”后才出现预览；编辑标题/正文，点击“创建便签”后仅新增一张，真正退出重启后仍存在。
- [ ] 分别在读取前、预览后取消，读取中按 Esc，并从独立设置窗口停用。预期取消不创建，迟到结果不复活弹窗或新增便签。
- [ ] 测试空剪贴板、图片等非文本、超过 64 KiB UTF-8 文本和 macOS 实际拒绝/延迟。预期可理解错误、可重试，不自动截断或创建。私密标记/延迟 provider 的可重复场景见第 14 步开发者检查。
- [ ] 若模拟保存失败：保留应用运行并点击重试。预期按同一 ID 保存，不重复建卡；未成功保存的内存草稿不保证进程退出后恢复。

## 5. 图片识字（OCR）

- [ ] 打开工具，点击选择图片。分别选择含中英文的 PNG/JPEG/WebP。预期使用本地识别，先展示可编辑预览；修改标题/正文并确认后只创建一张普通便签，重启后保留。
- [ ] 取消文件选择、识别中取消/停用、预览后取消。预期无自动建卡，迟到结果不创建便签。系统文件窗口/识别任务可能仍需等系统返回，期间再操作应提示忙碌。
- [ ] 选择无字、损坏、超 20 MiB、超 1600 万像素或单边超 8192 的图片，预期无字/无效/超限提示，可重新选择。HEIC、PDF 不在支持范围；屏幕捕获使用独立的屏幕工具。
- [ ] 断网重试正常图片，预期仍可识别并建卡。观察日志及 iframe 消息，预期不含原图、识别正文或个人路径，不调用 AI。

## 6. 图片工具

- [ ] 选择图片，核对预览和原始尺寸。开启保持比例修改宽度，预期高度联动；关闭后可独立输入。0、负数、单边超 8192 或总像素超 1600 万时禁止导出。
- [ ] 分别导出 JPEG、PNG、WebP，用系统预览或其他图像工具打开，核对实际格式和尺寸。JPEG 可调质量，透明区域填白；PNG/WebP 无损，保留 alpha，输出不保证更小。
- [ ] 检查 EXIF/GPS 等原始元数据不复制；比较原图导出前后的字节或哈希，预期原图未修改。选择原图作为输出应被拒绝，扩展名与格式不符应有提示。
- [ ] 取消选图、取消保存、选择无写入权限目录，预期无半成品且可重试；符号链接和 AppData 目标被拒绝。关闭弹窗/停用清除选图；超过 10 分钟再次导出提示重新选择。
- [ ] 导出中从独立设置窗口停用。预期已取消的选择无法开始新的写入；若最终原子写入已完成，则保留已完成的输出，不声称能够撤销已完成 IO。

## 7. 剪贴板历史

- [ ] 启用并打开工具，预期暂停、无历史。先复制“开始前文本”，再点击“开始记录”：预期不读取已有文本；随后在其他应用复制两段不含隐私的纯文本，等待约 1 秒，预期出现记录。
- [ ] 搜索一段文本，复制选中项并在测试编辑器粘贴，预期一致。删除单项不影响其他记录；重复复制同样内容不累积重复项。
- [ ] 点击“预览并创建便签”，修改并确认，预期只建一张；取消预览不建卡。复制或创建都必须由宿主按钮操作。
- [ ] 暂停后复制新文本，预期不再收集而旧历史保留。重新开始后只记录新的变化；清空后历史为空且暂停，迟到读取不能恢复被清空内容。
- [ ] 开始记录后关闭弹窗并复制新文本，再打开。预期记录继续，卡片状态可见；这是明确开启的后台行为。隐藏应用也继续记录，暂停/停用可停止。
- [ ] 分别从卡片、独立设置窗口停用，卸载、主页面重载、托盘退出再启动。预期旧历史清空、不自动恢复记录，不写历史文件；普通关闭主窗口仅隐藏，不等于退出。
- [ ] 测试非文本、超 64 KiB 文本，预期跳过。容量最多 100 条、合计 1 MiB、24 小时，超限淘汰旧项；不要为了验收使用真实密码。系统私密/临时/自动生成标记会过滤，未标记敏感文本可能被记录。

## 8. 文件暂存架

- [ ] 打开暂存架但不选文件，预期无自动导入；取消“添加文件”选择窗口不新增。选择两个普通测试文件，再次选择同一文件，预期按路径去重并显示新增/跳过数量。
- [ ] 从 Finder 拖入文件，预期仅暂存架弹窗打开时接受；关闭弹窗再拖入不记录。目录、符号链接、超过 100 MiB 的文件跳过；容量最多 50 项，超出有跳过提示。
- [ ] 搜索文件名、在 Finder 定位、另存副本，核对副本字节与原文件一致，原文件未移动/修改。取消保存不留半成品，权限失败后可重试；覆盖引用原文件、AppData 或符号链接目标应被拒绝。
- [ ] 重启后引用保留；移动/删除/替换测试原文件后刷新，预期显示不可用且不能导出。移除单项、确认/取消清空、停用/启用和卸载，预期只操作引用，原文件仍在；停用保留引用，卸载清除引用。
- [ ] 文件选择未结束时关闭/停用，随后选择结果不能新增引用；导出中停用不阻塞退出，已完成的输出不回滚。7 天逻辑过期、损坏备份/确认重置、未来 schema 不覆盖见自动化测试，使用隔离测试数据复查，不改真实索引。

## 9. 屏幕工具（选区、OCR、取色）

- [ ] 启用并打开工具，预期不自动申请系统权限或截图。点击截取才请求屏幕录制权限；分别拒绝/授权并按系统提示重启后重试，失败提示清晰，核心便签可继续使用。
- [ ] 使用不含隐私的测试画面选区，预期便签墙暂时隐藏、结果预览正确、操作完成恢复墙和焦点；Esc 取消不产生截图/便签。测试跨显示器、Retina 缩放和实际 WKWebView；不承诺录屏或连续捕获。
- [ ] 点击已知颜色区域，核对 HEX/RGB；使用原图 X/Y 坐标及键盘取色，边界坐标有效、越界禁止。点击“复制色值”后在测试编辑器粘贴，预期为显示的 HEX；其他操作不写剪贴板。
- [ ] 点击识别并预览，预期本地识别中英文，可编辑后确认仅创建一张便签；取消不建卡，重启后确认的便签仍在。断网可用，无字/超限/识别失败可重试。
- [ ] 导出 PNG 后用系统预览核对尺寸；取消保存、无权限目录、符号链接/AppData 目标和扩展名不符应有正确状态且无半成品。关闭/停用清除选择，10 分钟后旧 token 不再可用。
- [ ] 选区中从独立设置窗口停用、主页面重载、托盘退出，预期选区进程退出且不留下截屏十字线；迟到结果不复活预览/建卡，应用退出不重新弹出墙。正常完成后私有截图临时目录被清理；强杀遗留只在下次截图清理，不承诺强杀即时清除。

## 10. 本地工具、更新和回滚

- [ ] 链接清理：输入带 utm/fbclid 的测试链接，业务参数、重复查询参数和 fragment 保留；已知签名/token 链接不改写。无效协议/内嵌账户密码拒绝；不点击复制时剪贴板不变。
- [ ] 计算器：验证括号、幂、负数、sqrt/sin，除零/非法函数/超长算式有提示；复制结果一致，不执行输入代码。
- [ ] 文本片段：保存中英文多行、搜索、编辑、主动复制、删除；取消清空保留、确认清空删除。关闭/停用/重启保留片段，卸载清理；损坏/未来版本只报错和保留文件。
- [ ] 使用隔离测试插件做本地安装和更新，必须先预览并确认权限；取消无修改，超额/损坏/符号链接包失败后旧版仍能打开。重新加载能恢复上次中断替换。
- [ ] 在已安装行点击回滚，取消不改变版本；确认后恢复上一版且保持关闭，数据不降级。没有上一版有提示，未来 schema 不覆盖。内置原生工具旧资源与当前应用不匹配时需重新安装，不绕过字节校验。
- [ ] 检查公网 JSON 请求、超时/取消；私网 DNS、IPv6 隧道、重定向、超额响应、敏感 header 被拒绝或过滤。真实生产资源只允许背景目录，插件无法通过 asset 读取设置/密钥/片段。

## 11. 音频设备、媒体与每应用路由

- [ ] 重新安装原“音乐控制”（ID 不变，新版本 2.0）并启用。预期只显示启动卡片，不自动请求自动化/音频捕获授权。打开后核对真实设备，输入/输出默认设备切换、静音和音量；USB/HDMI 等只读设备有提示。操作前记下偏好，结束手动恢复。
- [ ] 先不启动播放器，预期提示；打开 Music/Spotify 并刷新，再读取/播放/暂停/上下首。首次自动化拒绝应可处理，授权重试展示真实曲目，无示例数据、不自动启动应用。
- [ ] macOS 14.2+ 播放两个不含隐私的测试音源。只路由所选音频进程到指定输出，把该路增益设为 0/50/100，另一音源不受影响；同时多路混音到同设备及分别路由不同设备。拒绝捕获权限/格式不兼容后，原音源继续播放。辅助进程可能单独列出，最多 4 路。
- [ ] 路由中关闭弹窗、隐藏页面、停用、卸载、重新安装、刷新墙、托盘退出；预期原路径恢复、活动资源释放，重开不恢复路由。切换采样率、断开输出、退出源应用、暂停恢复、睡眠唤醒；预期不可用流停止并显示可理解状态。记录丢帧/缺帧及 30 分钟 CPU/音质表现，不用模拟流程代替。
- [ ] 系统通知插件第一次发送可请求授权；拒绝应返回失败，允许后提交真实系统通知；专注模式下可不显示横幅。连续发送限流，核心便签提醒不被覆盖。

## 12. 窗口布局、切换和按需预览

- [ ] 未授权辅助功能时打开工具，应只有授权说明；主动授权后刷新。打开普通编辑器、浏览器和不可调整大小的窗口，搜索和切换，核对 PinWall 自己的窗口不列出。
- [ ] 分别应用左右/上下/四角/居中/填充；选另一显示器，包含负坐标、菜单栏/Dock、不同缩放。应用限制尺寸时提示；恢复按钮回到第一次变更前布局，刷新列表仍可恢复。关闭面板清除本次记录；不承诺恢复已关闭窗口。
- [ ] macOS 14+ 单击预览，屏幕权限拒绝应提示，允许后仅显示所选窗口；最小化/受保护窗口/窗口关闭/超时可处理。关闭或停用后不出现迟到图像，不写窗口截图文件。系统 Dock 悬停预览另列待开发，不算此步通过。

- [ ] 主动开启 Dock 预览，在底部/左右/自动隐藏 Dock、多个显示器、全屏空间测试：悬停普通运行应用最多四个可见窗口、点击正确切换，不预览 PinWall 或打开文件夹。关闭面板继续，停止/隐藏墙/睡眠/停用/重载/退出均销毁；撤销屏幕权限后停止，不出现迟到面板。记录 30 分钟空闲 CPU 和内存。

## 13. 输入增强（只用测试文本）

- [ ] 安装后默认关闭，启用/打开不监听。保存规则后点击开始，拒绝辅助功能/输入监控时明确失败，授权后可重试；重启不自动开始。
- [ ] 鼠标滚轮反向，选择仅离散滚轮时触控板方向不变；水平/垂直分别验证。Option+H/J/K/L、长按重复、先释放 Option、切换应用和停止时无卡住按键。
- [ ] 标准文本框使用 ;sig 加空格，替换中英文/换行/emoji；5 秒内 Cmd+Option+Z 恢复触发词，其他输入/移动光标/点击后不错误撤销。未匹配、超过 2 秒、非 ASCII 输入法不展开；记录应用兼容性。
- [ ] 默认排除的终端和密码管理器、安全输入和密码框不展开；新增排除 bundle ID 生效。输入日志和插件响应不含键入内容。
- [ ] 关闭面板仍运行；Stop、停用、卸载、墙重载、托盘退出均释放。停用保留规则、卸载清除；异常失去权限/系统停用 tap 不自动重启。30 分钟空闲与正常输入无明显延迟。

## 14. 视频处理与无声录屏

- [ ] 安装默认关闭、启用不录制；选择测试 MP4/MOV/M4V，检查旋转方向/时长/尺寸/音轨。取消选择不更换输入；超大、损坏、受保护、外部引用文件明确失败，不访问网络。
- [ ] 裁剪有效时间、480/720/1080p、MP4/MOV、保留/移除音轨；导出后在系统播放器核对时长/方向/声音。拒绝覆盖原视频、错误后缀、无写权限、磁盘不足；原视频和原目标不损坏，草稿可重试。
- [ ] 只在桌面放置无隐私测试图案。录制主显示器 15 秒，验证实际无声、提前停止后可保存 MOV、取消后无结果。拒绝录屏权限应可重试。不要用 UI 模拟测试代替真实授权和录制。
- [ ] 录制/编码中关闭弹窗、隐藏墙、停用、卸载、刷新及退出，确认进程回收、取消资源、临时副本清理；崩溃后下次使用清理旧工作目录。导出取消不损坏已存在目标。

## 15. 系统维护（仅准备可丢弃测试对象）

- [ ] 默认不开启扫描。用可丢弃的测试应用和缓存，主动列举、预览确认；默认不包含偏好文件。系统/Apple/PinWall 不在可处理对象中，正在运行应用拒绝卸载；普通权限不足明确失败，不提权。
- [ ] 只把测试对象移入废纸篓，验证会话恢复；原位置重建、对象被替换、部分失败不覆盖文件。重启后通过 Finder 废纸篓恢复；停用清除预览，重新安装不恢复旧计划。

## 17. 开发者自动化与难复现场景

以下命令不替代上面的人工项；provider 延迟、标记过滤、容量/TTL、保存失败、篡改和迟到结果已有可重复自动化测试。不要直接操作用户剪贴板模拟隐私内容。

```bash
# desktop/
pnpm test:run
pnpm build
pnpm test:e2e
# desktop/src-tauri/
cargo test --offline
cargo test --offline image_tools::tests::native_ocr_smoke -- --ignored --exact --nocapture
cargo test --offline clipboard::tests::native_clipboard_smoke -- --ignored --exact --nocapture
cargo test --offline desktop_tools::tests::native_audio_devices_smoke -- --ignored --exact --nocapture
cargo test --offline metrics::tests::native_metrics_smoke -- --ignored --exact --nocapture
cargo test --offline power::tests::native_assertion_smoke -- --ignored --exact --nocapture
```

OCR smoke 只使用合成图片；clipboard smoke 只读写私有命名 pasteboard；power smoke 会创建并释放短暂真实断言。浏览器以隔离 IPC 适配器测试真实 React/store 流程，未知命令仍报错，不能当作 TCC/文件窗口/实机运行已验收。
